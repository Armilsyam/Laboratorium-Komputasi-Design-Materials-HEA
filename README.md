# Laboratorium-Komputasi-Design-Materials-HEA
Laboratorium Komputasi

Berikut adalah implementasi penuh Laboratorium Komputasi Virtual (Virtual Computational Lab) berbasis dashboard Streamlit (app_virtual_lab.py) yang mengintegrasikan seluruh konsep Dual-Pipeline Hybrid AI (GAN + PINN + NSGA-II + SHAP) untuk desain material High-Entropy Alloys (Fe-Cr-Ni-Mo-Al) Reaktor Nuklir Generasi IV.

Seluruh perhitungan di dalamnya sudah dikalibrasi agar bebas dari anomali stagnasi nilai: biaya dihitung secara eksak dari fraksi massa, Yield Strength berada pada rentang realistis 900–1.480 MPa, dan batas elemen terkunci di koridor High-Entropy Alloy.
